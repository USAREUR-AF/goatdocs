## The fabric and its tools

goat itself: the mesh, identity and publish/subscribe fabric, the tools that build and run a goatnet, and the directory partners use to plan a link.

- [goatcore](https://github.com/USAREUR-AF/goatcore): goat: a self-hosted, open-source data fabric. WireGuard mesh (NetBird), brokerless Zenoh pub/sub and identity-based zero-trust access that keeps working when links fail. CLI, builder, roles and design record.
- [goat-client](https://github.com/USAREUR-AF/goat-client): Cross-platform daemon, GUI and CLI for goat's wg-cp0 control plane and inner mesh
- [netbird](https://github.com/USAREUR-AF/netbird): goat's NetBird fork: upstream netbirdio/netbird plus the client and management patches goat builds from
- [goatstuff](https://github.com/USAREUR-AF/goatstuff): goat peripheral surfaces and demos: panoscope, stethoscope, flashlight, netvis, microscope, trashgoat, gym, example apps.
- [saltlick](https://github.com/USAREUR-AF/saltlick): A peering directory for cross-sovereign federation: organisations publish their interconnection capability so two parties can check compatibility before building a link. Advisory, never authoritative; being listed grants nothing.

## Ways onto the fabric

For equipment, sensors, partners and feeds that are not goat: each one brings data onto a goatnet, or takes it off in a format another system reads.

- [zagros-moon-pod](https://github.com/USAREUR-AF/zagros-moon-pod): A self-contained pod a partner runs to join a goat data fabric and share data under their own custody.
- [octo-pod](https://github.com/USAREUR-AF/octo-pod): Edge appliance that connects equipment that cannot join a GOAT fabric: capture, identity, gated release and audit.
- [open-billie](https://github.com/USAREUR-AF/open-billie): Open Billie: sensor-neutral node platform that builds sensor kid packages and publishes normalized tracks (CoT, ASTERIX CAT062, SAPIENT) onto a Zenoh fabric. Apache-2.0.
- [first-bite](https://github.com/USAREUR-AF/first-bite): Decode binary messages off the wire against a declarative dictionary and publish them as JSON
- [open-entity-gateway](https://github.com/USAREUR-AF/open-entity-gateway): Publishes the records first-bite decodes as tracks over open interface standards (Cursor-on-Target, SAPIENT, ASTERIX CAT062), with optional vendor adapters as separate packages. Part of goat.

## Examples

Environments, worked examples and demonstrations to copy or run. Each hello-galaxy repository teaches one capability with steps you run.

- [goatenv](https://github.com/USAREUR-AF/goatenv): Example goat environment: one goatnet instantiation as an overlay repo consuming goatcore by pinned version.
- **first-bite-env** (not public yet): Example first-bite environment: a public example of the private overlay a first-bite deployment keeps its dictionaries and configuration in, the first-bite counterpart of goatenv.
- [goatrodeo](https://github.com/USAREUR-AF/goatrodeo): Games and toys that run on a goat data fabric; each one exercises Zenoh in public.
- [hello-galaxy-access-mgmt](https://github.com/USAREUR-AF/hello-galaxy-access-mgmt): rotate a live actor in place and detect and revoke a flooding one on a real Zenoh fabric, using the pre-cut UUID slot pool.
- [hello-galaxy-cross-env-federation](https://github.com/USAREUR-AF/hello-galaxy-cross-env-federation): end-to-end exercise of goat cross-environment federation, run against released artefacts.
- [hello-galaxy-external-service](https://github.com/USAREUR-AF/hello-galaxy-external-service): external service golden path: a service goat does not run borrows a goatnet's sign-in from one declaration, verifies tokens itself, authorizes from its own roster, and is withdrawn with no footprint. Runs on a laptop.
- [hello-galaxy-first-bite](https://github.com/USAREUR-AF/hello-galaxy-first-bite): first-bite: decode binary messages off a wire you cannot change and put them on a goatnet. Five runnable steps: decode a capture, tap a link, turn an interface document into a dictionary, publish to a goat fabric, make Cursor-on-Target.
- [hello-galaxy-goatenv](https://github.com/USAREUR-AF/hello-galaxy-goatenv): building a goat environment from goatcore, one verified step at a time.
- [hello-galaxy-grant-encryption](https://github.com/USAREUR-AF/hello-galaxy-grant-encryption): grant-keyed data-access encryption: a data owner restricts a stream to an audience by encrypting to it on a brokerless fabric, with nothing in the read path that can decrypt.
- [hello-galaxy-human-machine-onboarding](https://github.com/USAREUR-AF/hello-galaxy-human-machine-onboarding): human and machine onboarding: a person, then a machine, then a platform that decomposes into workloads, under one identity grammar. Runs offline.
- [hello-galaxy-legacy-feed](https://github.com/USAREUR-AF/hello-galaxy-legacy-feed): legacy feed carriage: an ASTERIX sensor arrives on a goatnet. Three runnable rungs (carry / mirror / decode) with framing lint, per-frame digest and a GeoTrackV1 adapter.
- [hello-galaxy-mesh-change-control](https://github.com/USAREUR-AF/hello-galaxy-mesh-change-control): mesh change control: the NetBird dashboard is for looking; group membership and access rules change through warrant, a reviewed diff in git applied by a machine. Runnable offline.
- [hello-galaxy-partner-data-sharing](https://github.com/USAREUR-AF/hello-galaxy-partner-data-sharing): partner data sharing: release data to one partner or a whole coalition on a deny-by-default fabric.
- [hello-galaxy-record-consumers](https://github.com/USAREUR-AF/hello-galaxy-record-consumers): record consumers: first-bite posts decoded records over HTTP; a receiver makes its PostgreSQL tables from the dictionary's JSON Schema and a board shows the latest status per source, on Kubernetes, with who may post and who may read granted by the data's owner.
- [hello-galaxy-spire-spiffe-patterns](https://github.com/USAREUR-AF/hello-galaxy-spire-spiffe-patterns): runnable proof that SPIRE/SPIFFE federation works: two trust domains, cross-domain mTLS, with an HTML report.
- [hello-galaxy-time-hygiene](https://github.com/USAREUR-AF/hello-galaxy-time-hygiene): time hygiene: on a brokerless fabric participants must agree with each other about time. Internal coherence vs UTC confidence, signed clock verdicts, and why a lying peer cannot capture the ensemble.
- [hello-galaxy-universal-id](https://github.com/USAREUR-AF/hello-galaxy-universal-id): universal identity: one portable identity descriptor consumed and enforced coherently across heterogeneous platforms.
- [hello-galaxy-zagros-pod](https://github.com/USAREUR-AF/hello-galaxy-zagros-pod): runnable moon-pod standup and bidirectional peering smoke test for a fictional partner, with registry-driven router configuration. Laptop loopback path plus your own goatnet.
- [hello-galaxy-zenoh-patterns](https://github.com/USAREUR-AF/hello-galaxy-zenoh-patterns): Zenoh usage patterns: when a single topic is right, key-expression design for retrieval, latest-vs-history storage.

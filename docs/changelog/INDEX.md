# Changelog

What changed across the goat repositories, for people who run or contribute to a goatnet. Each written entry covers a window of work across every public repository: it opens with what changed and what to do, lists the pull requests to read, and ends with what is still changing.

The [weekly listing](weekly/INDEX.md) is the complete record: one page per ISO week listing every merged pull request by kind, generated on a schedule from pull request titles.

| Entry | Covers |
|---|---|
| [2026-11-13-one-command-federation-stable-line.md](2026-11-13-one-command-federation-stable-line.md) | 10 to 13 November 2026: federation as one `goatbuilder federate` command (goatbuilder 0.5.1 and 0.5.3, goat 0.5.19), one development branch with a stable line that follows releases, what an outside contributor can expect, runs that name each command and leave a record (for 0.6.0), the gate and deprecation rule for goatbuilder 1.0, browser interfaces with no build step |
| [2026-11-10-signed-commits-one-build.md](2026-11-10-signed-commits-one-build.md) | 8 to 10 November 2026: signed and verified commits and the contributor-trust check required in every public repository, one build for every deployment (goat 0.5.18, goatbuilder 0.4.3), federation fixes and two proposed sharing decisions, federation as one goatbuilder command in review, refused secret references, the goatlite tutorial followed on clean machines |
| [2026-11-08-forty-eight-hours.md](2026-11-08-forty-eight-hours.md) | 6 to 8 November 2026: the move to public development, federation through the peering directory, the Postgres UTF8 migration, base images by role, contributor trust, advance notice of vulnerabilities, relay and portal hardening |

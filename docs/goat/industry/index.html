build on goat

Find where your product fits on goat, connect it, and show it working.

goat is an open-source data fabric: an encrypted mesh, identity for every person, machine and workload, and publish/subscribe data with no central broker. U.S. and allied forces in Europe run it today. The code, the guides and the worked examples are public, so your engineers can connect a product without asking anyone first.

OS="$(uname -s | tr '[:upper:]' '[:lower:]')"; ARCH="$(uname -m | sed 's/x86_64/amd64/; s/aarch64/arm64/')"
base=https://github.com/usareur-af/goatcore/releases/download/goat-cli-v0.5.20
curl -fsSL -o goat "$base/goat-$OS-$ARCH" && chmod +x goat
./goat hello

No account and no network: goat starts in a sandbox.

One integration works on every goatnet

Each nation runs its own goatnet and releases chosen data to its partners through boundary nodes. Every goatnet has the same open interfaces, so a product connected once runs on all of them.

Three notional nations. Diamonds are boundary nodes; a release set is the data one nation chooses to share. The figure scrolls sideways.

A security issue

Report it privately, as the security policy describes.

  • goat is built for secure unclassified networks. The public repositories hold no classified information, and none is needed to integrate a product.
  • A listing in awesome-goat is not an endorsement of any product, service or organization by the U.S. Army or the U.S. Government.
  • goat is before version 1.0. Build on the released versions each repository names.

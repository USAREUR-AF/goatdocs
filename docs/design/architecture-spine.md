## How to use this doc

CLAUDE.md is the index of *what's loaded into the system today*. The [ADR INDEX](https://github.com/usareur-af/goatcore/blob/main/docs/adr/INDEX.md) is the granular log of *every load-bearing decision*. This document is the layer between — the architectural spine: ~15 decision themes, each pointing at one or two anchor ADRs, the implementation block(s) tracking the work, and the load-bearing code paths.

When asking "where does X live?", start here. When the answer doesn't satisfy, follow the ADR or design-doc link. When the answer is "I don't know which area this falls in," skim the **Theme** column.

This doc is deliberately *narrow*. It is not a feature list. It does not cover every ADR. Sub-decisions live in their parent ADR; design specifics live in [`docs/design/`](.) ; implementation status lives in `../project/`. The spine is the orientation layer.

**Update rule.** When a new decision is load-bearing enough to be remembered by a returning contributor a year later, add a row. When a row's decision is superseded, mark the supersession in-place (don't delete) and link to the new anchor.
